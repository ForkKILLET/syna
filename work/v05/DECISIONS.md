| D21 | Independent audits run as fresh-context subagents writing only under `work/v05/audit/`; production fixes are applied by the main session with regression tests | keep | §5/§13 independence; no self-certified PASS. |
| D22 | `DependencyRef`s are slot-bound: a ref obtained from a child Env keeps working after that child is disposed while the slot's owner Env is alive | keep | Consistent with BoundEntry anchoring at the owner; K08 restricts new attempts by owner state. Audit F-PL-08. |

| D28 | Static builder writes `.hyla-build.json` and removes only files listed there; a non-empty directory without a manifest is refused | fix | H03 "禁止危险递归删除". Audit F-AP-08. |

| D41 | `preload()` stays, deprecated (alias of `void ref.load().catch(() => undefined)`, the structural discriminator of `loadAll`); no type-level thenable guard | keep | Removing it breaks M-02's discriminator; a thenable guard would leak into every instance type for a case the runtime already diagnoses (D17). | D42 | Site rotation is monotonic: an acquire joins the newest live (generation, configRevision) world of its tenant and drains only older ones; a capacity wait that outlives its read (generation moved, newer world created) releases the unit and re-reads, bounded by `acquireTimeoutMs` | fix | A stale read (replica lag, a cached read racing a save) or an `invalidate()` during the wait must neither drain the current world nor create one stale from birth (H10).
