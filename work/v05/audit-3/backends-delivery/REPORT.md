## Limits of this audit

- No cloud CI run exists (D53); `ci.yml` was checked only against the scripts it calls and the runner image's PostgreSQL 16 path.
- The round's claim that each group's new regressions fail on the pre-fix sources (STATE.md "Verification per group") requires rebuilding stashed sources and was not checked (no build allowed).
- Single machine (macOS 25.2, Node 26, PostgreSQL 17.10 temporary cluster with `fsync=off`); F-BD3-03's public-path frequency (20/20) and F-BD3-07's timing (1 s `deadlock_timeout`) are properties of PostgreSQL, not of this machine, but were not measured elsewhere.
